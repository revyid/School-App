**Dibuat:** 2026-10-13
**Revisi:** 2026-10-14 — TeacherClass DIHAPUS (shared data langsung dari TimetableSlot, tanpa sync)
**Status:** DRAFT

---

## Goal

Tambah halaman Jadwal untuk siswa, perbaiki alur Kelasku (card mapel → page mapel → buka tugas/asesmen), konsolidasikan admin (tab User gabungan Guru+Siswa, jadwal import global+libur+absensi-terhubung, sinkron otomatis jadwal↔guru, tambah tab Notifikasi admin).

---

## Current Context / Assumptions

- Skema: `TimetableSlot` (classId, subjectId, teacherId, dayOfWeek, startTime, endTime)
- Skema: `TeacherClass` (teacherId, classId, subject:String?) — cache penugasan guru; **bukan sumber kebenaran** jadwal
- Skema: `Subject` (schoolId, code, name) — master mapel
- Skema: `AcademicCalendar` (schoolId, date, kind: LIBUR|EFEKTIF, classId?, note)
- Skema: `AttendanceRecord` — unique per (schoolId, studentId, date); kolom `status`
- API `/api/timetable` sudah ada (GET, POST, PATCH, DELETE, export, import per kelas, subjects)
- API `/api/attendance/daily` dan `/monthly` sudah ada
- Admin sudah punya halaman terpisah: `/admin/siswa`, `/admin/guru`, `/admin/kelas`
- Sidebar admin saat ini: Dasbor, Siswa, Guru, Kelas, Jadwal, Kehadiran, Pengumuman | Pesan, Pengaturan, Audit, WA
- **Prinsip: gunakan data yang sudah ada. Jangan buat tabel baru kalau bisa pakai kolom existing.**

---

## Architecture / Proposed Approach

**Sumber kebenaran tunggal:** `TimetableSlot` adalah master penugasan guru-kelas. Tabel `TeacherClass` **dihapus total** (bukan di-sync) — semua pembaca (`guruClassIds`, API assignments, UI) query langsung ke `TimetableSlot` via helper di `server/lms-scope.ts`. `AcademicCalendar` dengan `kind=LIBUR` + rentang tanggal adalah satu-satunya sumber nonaktif absensi.

**Struktur navigasi baru:**
- Siswa: tambah menu "Jadwal" → `/siswa/jadwal`; Kelasku card mapel buka `/siswa/kelasku/[subjectId]` (drill-down per mapel)
- Admin: hapus menu Siswa, Guru, Kelas individual → ganti satu menu "Pengguna" → `/admin/pengguna` (tab Guru | Siswa, masing-masing fitur walikelas+mapel di tab Guru)
- Admin Jadwal: import all-kelas sekaligus; libur range tanggal dengan note; sync otomatis ke TeacherClass
- Admin: tambah menu "Notifikasi" → `/admin/notifikasi` (kirim push + WA massal)

### BLOK E — Admin Jadwal: Import Global (All-Kelas) + Libur Range Tanggal

**E.1 — Format import Excel baru (all-kelas)**

Kolom wajib: `Kelas | Hari | Mulai | Selesai | Mapel | Guru`

> Beda dari format lama yang hanya `Hari | Mulai | Selesai | Mapel | Guru` (per-kelas). Format baru punya kolom `Kelas` di depan sehingga satu file bisa untuk semua kelas.

File: `apps/web/server/timetable-xlsx.ts` — tambah fungsi `parseAllClassXlsx(buf)` di samping yang sudah ada.

```typescript
export function parseAllClassXlsx(buf: Buffer): {
  kelas: string; hari: string; mulai: string; selesai: string; mapel: string; guru: string;
}[] {
  const wb = XLSX.read(buf, { type: "buffer" });
  const ws = wb.Sheets[wb.SheetNames[0]];
  const rows = XLSX.utils.sheet_to_json<Record<string, string>>(ws, { defval: "" });
  return rows.map(r => ({
    kelas:   String(r["Kelas"] ?? r["kelas"] ?? "").trim(),
    hari:    String(r["Hari"] ?? "").trim(),
    mulai:   String(r["Mulai"] ?? "").trim(),
    selesai: String(r["Selesai"] ?? "").trim(),
    mapel:   String(r["Mapel"] ?? "").trim(),
    guru:    String(r["Guru"] ?? "").trim(),
  })).filter(r => r.kelas && r.hari);
}
```

## Risks & Tradeoffs

| Risiko | Mitigasi |
|--------|----------|
| Import all-kelas: nama kelas/guru tidak cocok (typo) | Return errors[] per baris, baris tidak cocok diskip + dilaporkan, tidak abort semua |
| TeacherClass sync race condition (2 request bersamaan upsert) | `upsert` Prisma sudah idempoten; worst case mapel jadi yang terakhir disimpan — acceptable |
| Libur range besar (365 hari) lambat | Batch upsert dalam 1 transaksi, max 365 dibatasi di server |
| Push broadcast ke 1000+ user lambat | Fire-and-forget via `Promise.allSettled`, return segera, log error di server |
| Hapus menu Siswa/Guru/Kelas dari navbar utama | Redirect 307 dipasang di masing-masing page supaya bookmark lama tetap bekerja |
| Kolom `homeroomTeacherId` baru → migrasi perlu jalan di prod | SQL `ADD COLUMN IF NOT EXISTS` idempoten, safe |
